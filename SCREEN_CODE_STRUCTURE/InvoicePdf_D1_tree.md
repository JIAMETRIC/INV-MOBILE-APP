# What's inside the invoice PDF (D1)

Files: `src/export/pdfTemplate.ts` (124 lines, `buildInvoiceHtml`) builds the page as HTML; `src/export/pdf.ts` (69 lines) turns it into a PDF and shares it; `src/export/pdfFonts.ts` holds the embedded fonts (generated by `scripts/build-pdf-fonts.py`, never edited by hand). Line numbers as of 2026-10-23.
Used by: S3 "Share PDF" (`InvoiceDetail.tsx:97`) and the live preview on S4 tablets (`CreateInvoiceScreen.tsx:164`).
IDs (D1.x) are from `SCREEN_LAYOUT_REFERENCE/SCREEN_LAYOUT_REFERENCE.md`.

This is a printed document: always black on white (`gray` scale from `tokens.ts`), whatever the app theme. It is plain HTML + CSS, not React Native, so the layout words are `display: flex`, `<table>`, `mm` and `px`.

## Functions

| Function | File:line | Does |
| --- | --- | --- |
| `esc(v)` | pdfTemplate.ts:8 | escapes `& < > "` so typed text can't break the HTML |

## Where to change what

| You want to change | Go to |
| --- | --- |
| page size (A4 / Letter) | `dims`, line 19; the user picks it on S4's preview (`pageSize` segmented control) — S3 always sends A4 (`InvoiceDetail.tsx:97`) |
| page margins | `body { padding: 10mm 9mm }`, line 43 |
| base text size or font | `body { font-size: 9.5px; font-family: … }`, line 46. The fonts themselves are in `pdfFonts.ts`; to add weights or characters, run `scripts/build-pdf-fonts.py` |
| number font or size | `td.n, .tot td.v { font-family: 'Bebas Neue'; font-size: 11.5px }`, line 59 |
| company name size | `.co`, line 50 (16px 700) |
| cell borders or padding | `th, td`, line 55 (1px `gray[300]`, `3px 4px`) |
| header rule | `.head`, line 49 (2px black) |
| column widths of the item table | the table has no fixed widths: it auto-sizes to content. To fix one, add `width` on its `<th>` (lines 99-100), e.g. `<th style="width:6%">#</th>` |
| totals block width | `.tot { width: 52% }`, line 60 |
| add a column to the items | three places: the `<th>` at 99-100, the `<td>` in `lineRows` at 21-26 (add `class="n"` for numbers), and the data: `InvoiceLine` in `src/data/types.ts` plus the SQL in `src/data/invoicesRepo.ts` if it is a new field |
| add a totals row | one `<tr>` in 106-109, same shape as Round Off |
| bill-to / ship-to box width | `.box { width: 49% }`, line 53 |
| text labels (BILL TO, Gross, TOTAL (₹), Authorised Signatory…) | the HTML at the lines in the tree; they are literal strings |
| the saved file's name | `safeNo`, pdf.ts:40 (`<invoice_no>.pdf` in `Documents/Invoices`) |
| the share dialog title | pdf.ts:57 |

Not used on screen: `gray` is a print palette only (`tokens.ts:4`). The app's theme tokens (`theme.*`) are never used here on purpose.
