# Invoice PDF (D1) — Three-Slot tree

**Files:** `src/export/pdfTemplate.ts` (123 lines, `buildInvoiceHtml`) builds the page as HTML; `src/export/pdf.ts` (68 lines) turns it into a PDF and shares it; `src/export/pdfFonts.ts` (7 lines) holds the embedded fonts, generated by `scripts/build-pdf-fonts.py` and never edited by hand. Line numbers as of 2026-10-23 · **Reached by:** S3.3 "Share PDF" (`InvoiceDetail.tsx:118`, inside `share('pdf')` at 114) and the live preview on S4 (`CreateInvoiceScreen.tsx:196`, which calls `buildInvoiceHtml` directly with the form's lines and the A4 / Letter control at 720) · **Data:** `getInvoice`, `getLines` (`src/data/invoicesRepo.ts`) and `getSettings` (`src/data/settingsRepo.ts`), all loaded by `exportInvoicePdfHtml` (`pdf.ts:29-34`) · **Reference:** `SCREEN_LAYOUT_REFERENCE/SCREEN_LAYOUT_REFERENCE.md` § D1 · **Method:** `.claude/skills/three-slot-screen/SKILL.md`, read as the Header / Body / Footer of a printed page

A printed page, not a screen: plain HTML and CSS, rendered to PDF by `expo-print` on Android, downloaded as an HTML file on web, and shown in a `WebView` on the S4 preview. Always black on white (the print greys `gray` in `src/ui/tokens.ts:4-8`), whatever the app theme; the theme tokens are never used here. The layout words are `display: flex`, `<table>`, `mm` and `px`.

## 6. Functions

| Function | File:line | Does |
| --- | --- | --- |
| `esc(v)` | pdfTemplate.ts:8 | escapes `& < > "` so typed text cannot break the HTML |
| `money(p)` | pdfTemplate.ts:11 | paise to a grouped two-decimal string without the ₹ sign (the sign is in the TOTAL label) |
| `buildInvoiceHtml(inv, lines, s, pageSize = 'A4')` | pdfTemplate.ts:13 | returns the whole page as one HTML string; `dims`, `lineRows` and `shipBlock` are built first (19-34) |
| `PDF_FONT_CSS` | pdfFonts.ts:3 | the three `@font-face` rules joined with newlines, pasted into the `<style>` at line 39 |
| `isWeb` | pdf.ts:9 | `Platform.OS === 'web'`; every branch below keys on it |
| `docsDir(...segments)` | pdf.ts:11 | creates (idempotently) and returns `Documents/<segments>`; throws on web; also used by `saveXlsx` (D2) |
| `webBlobDownload(data, filename, mime = 'text/html')` | pdf.ts:19 | Blob to object URL to a clicked `<a download>`; returns the URL; also used by D2 on web |
| `exportInvoicePdfHtml(invoiceId, pageSize)` | pdf.ts:29 | `getInvoice` (throws "Invoice not found"), then `getSettings` and `getLines` in parallel, then `buildInvoiceHtml` |
| `exportInvoicePdf(invoiceId, pageSize = 'A4')` | pdf.ts:36 | throws on web; HTML through `Print.printToFileAsync`, then moved to `Documents/Invoices/<safeNo>.pdf`, deleting an existing copy first because `moveSync` refuses to overwrite; `safeNo` is the invoice number with every character other than letters, digits, `_` and `-` replaced by `-` (40) |
| `shareFile(uri)` | pdf.ts:49 | web: returns for a `blob:` URL (the download already ran), throws otherwise; Android: throws when no share target exists, else `Sharing.shareAsync` with the title "Share file" |
| `exportInvoicePdfAndShare(invoiceId, pageSize = 'A4')` | pdf.ts:60 | the call S3 makes (always A4): on web an HTML download named `invoice-<id>.html`; on Android `exportInvoicePdf` then `shareFile` |

## 7. Where to change what

| You want to change | Go to |
| --- | --- |
| page size (A4 / Letter) | `dims`, pdfTemplate.ts:19; S4's preview picks it with its "Page size" control (`CreateInvoiceScreen.tsx:720`); S3 sends no size, so A4 (`pdf.ts:60`) |
| page margins | `body { padding: 10mm 9mm }`, line 43 |
| base text size or font stack | `body { font-size: 9.5px; font-family: … }`, line 46. The fonts themselves are in `pdfFonts.ts`; to add weights or characters, rerun `scripts/build-pdf-fonts.py` and commit the file |
| number font or size | `td.n, .tot td.v { font-family: 'Bebas Neue'; font-size: 11.5px }`, line 59 |
| company name size | `.co`, line 50 |
| cell borders or padding | `th, td`, line 55 |
| header rule | `.head`, line 49 |
| column widths of the item table | none are set; add `width` on a `<th>` at lines 99-100 (for example `<th style="width:6%">#</th>`) |
| totals block width | `.tot { width: 52% }`, line 60 |
| add a column to the items | three places: the `<th>` at 99-100, the `<td>` in `lineRows` at 21-26 (add `class="n"` for a number), and the data (`InvoiceLine` in `src/data/types.ts:54-62` plus the SQL in `src/data/invoicesRepo.ts` when the field is new) |
| add a totals row | one `<tr>` among 106-109, in the shape of Round Off |
| bill-to / ship-to box width | `.box { width: 49% }`, line 53 |
| text labels (BILL TO, Gross, TOTAL (₹), Authorised Signatory …) | the literal strings at the lines in the tree |
| what the footer shows when a field is empty | the conditionals at 116, 117 and 119 |
| the saved file's name or folder | `safeNo` and `docsDir('Invoices')`, pdf.ts:40-42 |
| the web download's name | pdf.ts:63 |
| the share dialog title | pdf.ts:57 |
| print greys | `gray` in `src/ui/tokens.ts:4-8` (never a literal colour in the template) |
